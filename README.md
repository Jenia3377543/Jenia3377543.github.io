# jenia3377543.github.io

Public pages for the Android app **Theory Champion (אלוף התאוריה)**, served by GitHub Pages
(Jekyll) at <https://jenia3377543.github.io>.

- `privacy-policy.md` → `/privacy-policy/` (also the Play Console privacy policy URL)
- `terms.md` → `/terms/`
- `bug-report.md` → `/bug-report/` (embeds the Google Form)
- `app-ads.txt` → `/app-ads.txt` (AdMob seller declaration)

The app opens these URLs from `LegalLinks.kt`. Don't rename the pages without updating the
app and the Play Console. Edit a page, update its "Last updated" date, push to `main`.
